# Latest TMS ERP package

The latest standalone webpage is `index.html` at the repository root. It runs locally in the browser and does not provide server-backed authentication.

The complete updated sources are in `TMS-GitHub.zip`; extract it to obtain the standalone page, tests and `online` folder. `TMS-online.zip` contains the server edition with administrator-created accounts, student learning, quizzes, internal messages, timetable allocation and email setup instructions.

For the latest hosted edition, extract `TMS-online.zip` and follow its README.md and EMAIL-SETUP.md. Older loose files and the previously uploaded TMS-GitHub directory have been retained; use the new archive for the current server edition.

GitHub Pages can display the standalone page, but cannot run the Node/SQLite server. Secure online login and shared records require server deployment.
